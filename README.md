## AI-assisted engineering

I wrote and maintain Neocoast's AI engineering standard for delivering software with AI agents across our products and client work.

It covers authority and risk, data and trust, process, evidence, code quality, and cost. The core principle is simple: every rule needs an enforcement mechanism, whether that is a hook, CI check, review step, or PR template.

I built Neocoast's internal toolkit: 27 Claude Code skills distributed through an auto-updating plugin marketplace for developers, designers, PMs, and QA. For QA, I built an agent framework with atomic skills and an orchestrator that explores an application, generates test cases, and runs them in the browser with human checkpoints.

I apply the same standard to my own work: hooks protect production branches, test workers are limited by available RAM, CI minutes are treated carefully, and skills can drive a real iPhone from a Mac through XCUITest for end-to-end QA.
